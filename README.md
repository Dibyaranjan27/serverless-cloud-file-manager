Demonstrated`n`n| Concept | Where It's Used |`n|---|---|`n| **Serverless Compute** | AWS Lambda automatically extracts metadata in the background without provisioning servers |`n| **Event-Driven Architecture** | S3 `s3:ObjectCreated:*` events automatically trigger the Lambda pipeline |`n| **Object Storage** | Uploaded files are streamed directly into an Amazon S3 bucket |`n| **NoSQL Databases** | Amazon DynamoDB stores the extracted file metadata for fast retrieval |`n| **Containerization** | The entire multi-service stack is orchestrated using Docker Compose |`n`n---`n`n## 📌 Key Features`n`n- ☁️ **Full Local AWS Simulation** — Zero cloud costs, runs completely offline.`n- 📁 **Batch Processing** — Select and upload dozens of files simultaneously.`n- ⚡ **Asynchronous Extraction** — Background Lambda functions handle processing to keep the UI fast.`n- 🔍 **Instant Search** — Real-time client-side search filtering for massive file lists.`n- 📱 **Mobile Responsive** — Custom stacked-card layout for viewing files on small screens.`n- ⬇️ **Direct Downloads** — Stream your uploaded files back directly from S3.`n- 🎨 **Glassmorphism UI** — Beautiful, modern frontend design.`n`n---`n`n## 🏗️ Architecture Analysis`n`n### The Event Pipeline`n`nThe data pipeline follows a strict, decoupled, asynchronous flow:`n`n````nUser Upload ──> S3 Bucket ──(Event Trigger)──> AWS Lambda ──> DynamoDB Table`n                                                                      │`nUser Dashboard <──────────────────────────────────────────────────────┘`n````n`n1. **Upload**: The Flask app acts solely as an API gateway, streaming the binary file into S3.`n2. **Event**: S3 fires an `ObjectCreated` event containing the file's Amazon Resource Name (ARN).`n3. **Compute**: Lambda boots up instantly, parses the event, retrieves the file size and timestamp, and formats it.`n4. **Database**: Lambda writes a new record into DynamoDB.`n5. **Retrieval**: When the user requests the page, Flask runs a quick table scan on DynamoDB to render the UI.`n`n---`n`n## 🛠️ Tech Stack`n`n- **Backend:** Python 3.9, Flask, Boto3 (AWS SDK)`n- **Frontend:** HTML5, CSS3, Vanilla JS, Jinja2`n-
